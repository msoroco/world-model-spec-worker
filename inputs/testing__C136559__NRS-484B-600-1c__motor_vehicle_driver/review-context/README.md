# C136559 / NRS-484B-600-1c

## Law

**NRS-484B-600-1c — Basic rule (1)(c)**

> It is unlawful for any person to drive or operate a vehicle of any kind or character at: A rate of speed greater than that posted by a public authority for the particular portion of highway being traversed.
